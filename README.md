# X 未回关筛选

Chrome 扩展。在 X 的「正在关注」列表里，筛出你已经关注、但对方没有回关的账号，并可以单个或批量取消关注。

## 安装

1. 打开 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 解压 `x-weihuanguan-1.0.0.zip`，或直接使用本仓库目录。
4. 点「加载已解压的扩展程序」，选择解压后的目录。

修改代码后，在扩展管理页点一次「重新加载」，再刷新 X 页面。

## 使用

未回关的人在「正在关注」里。已认证关注者和关注者都已经关注了你，那两个页面不会出现「对方没回关」的人。

打开自己的正在关注页，例如：

`https://x.com/你的用户名/following`

页面右上角会出现「未回关筛选」：

- **自动扫描**：从列表顶部往下翻，识别当前能加载到的账号。
- 名单里只保留按钮是「正在关注 / Following」、且没有「关注了你 / Follows you」的人。这些人会用红框标出，其他人会变淡。
- **取消关注**：取消单个。
- **全部取消关注**：先确认，再大约每 2 秒取消一个。**停止**可以中断。
- **收起**：面板收成红色的「未回关」按钮，再点即可展开。扩展图标里的「显示 / 收起面板」作用相同。

X 一次只渲染一段列表，人很多时需要等自动扫描翻完。批量取消留了间隔，避免触发 X 的操作限制。

## 文件

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 扩展清单 |
| `content.js` / `content.css` | 页面上的筛选面板和取消关注 |
| `popup.html` / `popup.js` / `popup.css` | 工具栏弹窗 |
| `icons/` | 扩展图标 |
| `dev-fixture.html` | 本地夹具页，用来检查识别和取消关注，不需要装进浏览器 |
